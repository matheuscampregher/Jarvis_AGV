Conectar sem Google Cloud

A planilha guarda os dados; quem você executa é o Jarvis. Você pode conectar pelo link ou selecionar uma cópia Excel. Esses dois modos não pedem cartão, pagamento ou JSON Google.

Já abriu o configurador antigo? Feche aquela janela. Extraia este novo ZIP em outra pasta e use o Jarvis.py desta versão (opção 2). Se escolher o modo 1 ou 2 e aparecer uma solicitação de JSON, você ainda está executando a versão antiga.

1. Prepare a pasta

  1. Feche o Jarvis antigo e extraia o ZIP inteiro em uma nova pasta.
  2. Abra a pasta que contém Jarvis.py.
  3. Execute Jarvis.py (opção 1 — Instalar) e aguarde a conclusão. A instalação precisa de internet; não cria conta Google.
  4. Execute Jarvis.py (opção 2 — Configurar a planilha).

Pelo CMD: abra essa pasta no Explorador de Arquivos, clique na barra de endereço, digite cmd e pressione Enter. Depois execute cada comando quando o anterior terminar:

Jarvis.py   (opção 1, depois opção 2)

Leitura pelo link não é acesso privado. Qualquer pessoa com o link também pode ler os dados. Use esse modo somente se essa visibilidade for permitida para o conteúdo. Se os dados devem ficar privados, escolha 2. O Jarvis não muda permissões, não publica a planilha e não envia convites.

3A. Se escolheu 1: cole o link normal

  1. Em Modo de acesso [1], digite 1 e pressione Enter.
  2. Em Cole o link da planilha, cole o mesmo link que você abre no navegador. Para a planilha sugerida abaixo, basta pressionar Enter.
  3. Em Formato [1], pressione Enter.
  4. Confira as abas Professores, Disciplinas, Turmas e Horário DS1. Pressione Enter se os nomes estiverem corretos. Se mudou um nome, digite N para informar o novo.
  5. Aguarde a mensagem Leitura confirmada. Não é necessário entrar no Google Cloud nem escolher JSON.

Se aparecer “Sem leitura pelo link”, teste abrir e baixar a planilha numa janela anônima. O modo 1 precisa de acesso sem login e download permitido. Se você estiver autorizado a liberar esses dados, a opção é Compartilhar → Acesso geral → Qualquer pessoa com o link → Leitor. Não dê acesso de edição. Se não puder liberar, escolha o modo 2. Não é necessário usar “Publicar na Web”.

3B. Se escolheu 2: mantenha a planilha privada

  1. Abra a planilha no Google com sua conta habitual.
  2. Clique em Arquivo → Fazer download (ou Baixar) → Microsoft Excel (.xlsx). Um único arquivo inclui todas as abas.
  3. No Jarvis.py (opção 2 — Configurar a planilha), digite 2 em Modo de acesso.
  4. Na pergunta sobre o arquivo Excel, pressione Enter e selecione o arquivo baixado na janela. Alternativamente, cole o caminho completo do .xlsx.
  5. Mantenha Formato 1 e confirme os nomes das abas com Enter.
  6. Aguarde Leitura confirmada. A cópia fica em dados/grade.xlsx, no computador que executa o Jarvis.

Se sua planilha já está aberta pelo link, o modo 2 não a torna privada automaticamente. Para fechar esse acesso, ajuste no Google Compartilhar → Acesso geral → Restrito. A cópia local continua funcionando.

Para atualizar: edite no Google, espere as fórmulas calcularem, baixe outro .xlsx e execute novamente o configurador no modo 2. Esse modo não sincroniza sozinho. O Jarvis lê os resultados das fórmulas salvos no arquivo; não calcula fórmulas do Excel.

A pasta dados fica fora da parte pública do site e não é servida pelo navegador. Guarde o projeto no computador servidor; não distribua essa pasta aos alunos. Quem tiver acesso aos arquivos do computador poderá lê-la, e quem acessa o Jarvis poderá consultar os horários exibidos.

4. Confira os dados e inicie

Erros mais comuns

MensagemO que fazer
Pede JSONVocê escolheu o modo 3 ou abriu a versão antiga. Execute o novo configurador e escolha 1 ou 2.
Pede pagamento no Google CloudFeche essa página. Os modos 1 e 2 não usam o console Google Cloud.
Não há acesso pelo linkConfira a leitura e o download sem login; se a planilha deve permanecer privada, use modo 2.
Horário Inicial vazio, linha 14Preencha B14 e confira C14. No modo 2, baixe a planilha novamente.
Aba não encontradaConfirme o nome exato: Horário DS1. Ajuste os nomes no configurador se renomeou alguma aba.
Arquivo não é XLSX válidoBaixe como Microsoft Excel (.xlsx). Não use CSV, HTML ou um atalho para a planilha.
Editei, mas não atualizouNo modo 1, aguarde o cache e pergunte novamente. No modo 2, baixe e selecione o arquivo atualizado.
